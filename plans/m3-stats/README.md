# M3: Stats Tab

**Depends on:** M0, M1

## What
New Stats navigation tab with weight tracking, biomarkers with optimal longevity ranges, biological age calculation, DEXA scan import, a food-to-feeling correlation engine, and Bristol Stool Scale logging.

## Why
Users need a centralized place to see trends, body composition, and health markers over time. The correlation features (food-to-feeling, Bristol Stool) turn raw data into actionable personal insights.
